## 🖤 What is LeetCo?

LeetCo is a **Chrome extension** that enhances your LeetCode experience by showing:

- 🏷️ **Which companies asked a problem**
- ⏳ **How recently it was asked**
- 🧠 **Company frequency insights**
- 🎨 Clean badges with company logos

All of this appears **directly on the LeetCode problem page** — no tab switching, no distractions.

---

## ✨ Features

- 🔍 Detects LeetCode problem automatically
- 🏢 Displays company badges with logos
- ⏱️ Time-range based insights (recent → all-time)
- ⚡ Fast API-backed responses
- 🌙 Beautiful dark, glassmorphism UI
- 🧩 Works seamlessly with LeetCode SPA navigation

## ⬛ Installation Guide (Chrome)

Follow these steps to install **LeetCo — Company Insights** locally in your browser.

---

### 1️⃣ Download the Extension Code

1. Open the GitHub repository: https://github.com/VikrantKadam028/LeetCo---Company-Insights

2. Click on the **Code** button (top right).

3. Select **Download ZIP**.

4. Once downloaded, **extract (unzip)** the folder on your system.

You should now have a folder containing files like:
- `manifest.json`
- `content.js`
- `popup.html`
- `styles.css`
- `background.js`

---

### 2️⃣ Open Chrome Extensions Page

1. Open Google Chrome  
2. In the address bar, type: chrome://extensions
3. Press **Enter**

---

### 3️⃣ Enable Developer Mode

1. Look at the **top-right corner** of the Extensions page  
2. Turn **Developer mode** ✅ ON

This will reveal new buttons on the page.

---

### 4️⃣ Load the Extension

1. Click on **Load unpacked**
2. Select the **extracted LeetCo folder** (the folder that contains `manifest.json`)
3. Click **Select Folder**

✅ The extension will now be installed instantly.

---

### 5️⃣ Verify Installation

- You should see **LeetCode Company Insights (LeetCo)** listed in extensions
- The LeetCo icon will appear in the Chrome toolbar (you may pin it)

---

### 6️⃣ Use LeetCo

1. Open: https://leetcode.com/problems/
2. Open any problem (example: *Two Sum*)
3. Scroll near the problem title

🎯 Company insights will appear automatically on the page.
